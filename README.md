# Kita Berkah Teknik

Website resmi **Kita Berkah Teknik** — Jasa Service AC Profesional (Jakarta & sekitarnya).

## Fitur

- Landing page lengkap (Hero, Layanan, Harga, Tentang, Keunggulan, Testimoni, Kontak)
- Booking form interaktif dengan kalkulasi total otomatis (Rupiah)
- Kirim booking langsung via WhatsApp
- Desain responsive (mobile-first)

## Stack

- HTML5 + CSS3 (vanilla, tanpa framework)
- Font Awesome 6
- Google Fonts (Inter)
- JavaScript murni

## Pengembangan

```bash
# Jalankan lokal
python3 -m http.server 8000
# buka http://localhost:8000
```

## Deploy

Static site — deploy di Vercel / Netlify / GitHub Pages cukup dengan point ke folder root.
